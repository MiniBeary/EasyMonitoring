# Security policy

## Поддерживаемые версии

Исправления безопасности выпускаются для последнего публичного release. Pre-release может содержать известные ограничения, перечисленные в release notes.

## Как сообщить об уязвимости

Не создавайте публичный issue для уязвимости. Используйте [GitHub Security Advisories](https://github.com/MiniBeary/EasyMonitoring/security/advisories/new), чтобы отправить приватный отчёт.

В отчёте укажите:

- версию EasyMonitoring и Windows;
- шаги воспроизведения;
- потенциальное влияние;
- минимальный proof of concept, если он безопасен.

EasyMonitoring запускается с правами администратора, читает аппаратные сенсоры и создаёт задачу Task Scheduler. Особенно важны отчёты, связанные с этими компонентами, путями к exe и обработкой внешних данных.
